# CoverCard

A web app for creating and sharing digital proof-of-insurance cards (eSlips), so you don't have to dig around for the paper pink slip every time you need it.

I worked on a proof-of-insurance platform as a consultant a few years ago and wanted to build my own version from scratch, this time with the MERN stack.

Still a work in progress.

# Tech Stack

React + TypeScript (Vite) on the frontend, Node/Express API, MongoDB with Mongoose.
